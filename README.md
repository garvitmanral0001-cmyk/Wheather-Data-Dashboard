# 🌦️ Weather Analytics Dashboard

An interactive Power BI dashboard built using real-time weather data from the OpenWeather API. This project demonstrates API integration, data transformation, and data visualization to provide insights into weather conditions across different locations.

## 🚀 Features
- Fetches real-time weather data using OpenWeather API
- Data cleaning and transformation with Power Query
- Interactive Power BI dashboard
- KPI cards for Temperature, Humidity, and Wind Speed
- Dynamic filters and slicers for location-based analysis
- Weather trend visualization and comparison

## 🛠️ Tech Stack
- Power BI
- OpenWeather API
- Power Query
- Python
- REST API

## 📊 Dashboard Insights
- Current Temperature Analysis
- Humidity Monitoring
- Wind Speed Tracking
- Weather Condition Overview
- City-wise Weather Comparison

## 📂 Project Workflow
1. Collect real-time weather data from OpenWeather API.
2. Clean and transform data using Power Query.
3. Load transformed data into Power BI.
4. Create KPIs, charts, and interactive visualizations.
5. Analyze weather patterns and trends.

## 🔑 API Source
Weather data is sourced from the OpenWeather API using a developer API key obtained through the OpenWeather platform.
